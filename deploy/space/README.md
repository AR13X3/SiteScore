# SiteScore: live demo

An open-source simulator that projects 36 months of revenue for any street corner, compares sites and explains why each one wins or loses.

**Source, docs and how to run it yourself:** https://github.com/AR13X3/SiteScore

This Space is deployed automatically from the GitHub repository's `main` branch: change the code there, not here. The model, map and backtest run live. The AI analyst replays recorded runs, because this demo has no language-model key. Clone the repository and add your own OpenRouter key to ask it anything.
